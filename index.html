Architecting for High Availability (HA)

To demonstrate proficiency in Infrastructure as a Service (IaaS), I manually built a fault-tolerant environment on Azure. This setup utilizes an Azure Load Balancer to distribute traffic between multiple Virtual Machines housed within an Availability Set.

Fail-Safe Mechanism: If VM1 encounters an outage, the Load Balancer automatically re-routes traffic to VM2 via real-time Health Probes, ensuring Zero Downtime for the end user.

The entire infrastructure is isolated within a secure Virtual Network (VNet), demonstrating a professional-grade approach to cloud resource management and system resilience.
